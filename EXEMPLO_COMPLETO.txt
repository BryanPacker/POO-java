🎯 OBJETIVO
───────────
Demonstrar um projeto COMPLETO que mistura:
  ✓ Classe modelo (Livro.java)
  ✓ Gerenciador de dados (Biblioteca.java)
  ✓ Interface gráfica (BibliotecaGUI.java)
  ✓ Persistência em arquivo (CSV)
  ✓ Testes (TesteBiblioteca.java)


📂 ARQUIVOS
───────────

1. Livro.java
   └─ Classe modelo com ID automático
   └─ Métodos paraArquivo() e deArquivo() para serialização
   └─ Getters, setters, toString()

2. Biblioteca.java
   └─ Gerencia ArrayList<Livro>
   └─ Operações: buscar, remover, calcular, salvar/carregar
   └─ Acesso a arquivo (FileWriter/FileReader)
   └─ Tratamento de exceções

3. BibliotecaGUI.java (13 KB - a mais complexa)
   └─ JFrame com 4 abas principais:
      1. Adicionar livro (formulário com validação)
      2. Buscar (por título ou autor)
      3. Visualizar (estatísticas)
      4. Gerenciar (remover, salvar, carregar)
   └─ ActionListener para cliques
   └─ Diferentes layouts (Grid, Flow, Border)
   └─ JOptionPane para mensagens

4. TesteBiblioteca.java (Testes sem GUI)
   └─ Demonstra todas as operações
   └─ Output formatado para entender fluxo
   └─ Pronto para copiar como estrutura de testes

5. README.md
   └─ Documentação completa
   └─ Guia de uso
   └─ Exemplos de código para copiar


🚀 COMANDOS RÁPIDOS
───────────────────

COMPILAR TUDO:
  javac -d bin src/estudos/exemplo_completo/*.java

RODAR GUI (interface gráfica com janelas):
  java -cp bin estudos.exemplo_completo.BibliotecaGUI

RODAR TESTES (sem GUI, mostra saída no terminal):
  java -cp bin estudos.exemplo_completo.TesteBiblioteca


✅ O QUE VOCÊ APRENDE
─────────────────────

Conceitos de POO:
  • Classe modelo com atributos privados
  • Encapsulamento (getters/setters)
  • Static para ID automático
  • toString() para formatação

Coleções:
  • ArrayList: adicionar, remover, iterar
  • For-each loop
  • Busca com contains()

Arquivo/Persistência:
  • FileWriter para escrever
  • FileReader para ler
  • BufferedReader para leitura eficiente
  • PrintWriter para escrever linhas
  • Formato CSV (separado por vírgula)
  • Validação de arquivo existente

GUI/Swing:
  • JFrame (janela principal)
  • JTabbedPane (abas)
  • JTextField, JTextArea, JButton, JLabel
  • Layouts: GridLayout, FlowLayout, BorderLayout
  • ActionListener para eventos
  • JOptionPane para diálogos

Validação:
  • Campos vazios (isBlank())
  • Números (try-catch NumberFormatException)
  • Ranges (idade, preço, etc)
  • Duplicatas

Padrões:
  • Model-View-Controller (MVC)
  • Separação de responsabilidades
